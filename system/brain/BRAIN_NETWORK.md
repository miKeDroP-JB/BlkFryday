## Usage

### Initialize the Hub

```javascript
const { BrainNetworkHub } = require('./system/brain');

const hub = new BrainNetworkHub();
await hub.initialize();
```

### Build Anything

```javascript
// Natural language input
const result = await hub.build('Create a SaaS landing page for fintech');

// Quick build by type
const saas = await hub.quickBuild('SAAS_APP');

// Quality-focused (uses tournament mode)
const premium = await hub.qualityBuild('LANDING_PAGE');

// Creative (uses resonance mode)
const innovative = await hub.innovativeBuild('BRAND');
```

### Generate Landing Pages

```javascript
// Full config
const page = await hub.generateLandingPage({
  pageType: 'PRODUCT_LAUNCH',
  industry: 'SAAS_TECH',
  companyName: 'My Startup',
  product: 'Magic Tool',
  benefit: 'productivity',
  audience: 'teams'
});

// Quick generate
const quick = await hub.quickLandingPage('Acme Corp', 'SuperWidget', 'ECOMMERCE');
```

### Process with Brain Network

```javascript
// Simultaneous (fast)
const fast = hub.process('Analyze this data', 'SIMULTANEOUS');

// Tournament (best)
const best = hub.process('Generate marketing copy', 'TOURNAMENT');

// Resonance (creative)
const creative = hub.process('Invent new product concepts', 'RESONANCE');
```

### Get Status

```javascript
const status = hub.getStatus();
console.log(`Active Agents: ${status.network.availableAgents}`);
console.log(`Tasks Processed: ${status.stats.totalTasksProcessed}`);
```
