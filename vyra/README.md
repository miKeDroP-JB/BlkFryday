## What Is This?

A custom Arch-based Linux distribution built for:
- AI agent development and orchestration
- Local LLM deployment
- Swarm intelligence systems
- Reality engineering workflows

## Quick Build

```bash
# Build the ISO
./build.sh

# Output: vyra-genesis-YYYYMMDD.iso
```

## Components

| Layer | Description |
|-------|-------------|
| **Base OS** | Arch Linux minimal + custom kernel |
| **WarpDrive ZSH** | Agent-aware shell with spellcasting |
| **AI Stack** | Ollama, LangChain, local LLMs, embeddings |
| **Visual Layer** | Neon sigils, reactive glyphs, trap beats |
| **Channel 0** | Personal intent interface |
| **Swarm Panel** | Real-time agent orchestration GUI |

## Boot Options

- **Live Mode** - Full system from USB/SSD
- **Persistent Mode** - Save changes across reboots
- **Install Mode** - Full disk installation

## Post-Boot

On first boot, VYRA automatically:
1. Activates WarpDrive ZSH
2. Launches Channel 0 daemon
3. Spins up Swarm Panel
4. Starts visual ritual layer
5. Enables default macros

## Requirements

- 8GB+ RAM (16GB recommended)
- 64GB+ storage
- NVIDIA GPU recommended for inference
- UEFI boot support
